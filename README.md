# Bhavisha Aswani — Portfolio

Personal portfolio website built with React + Vite. Live at **[bhavisha-aswani.vercel.app](https://bhavisha-aswani.vercel.app)**

---

## About

Senior .NET & Full-Stack Developer with 5+ years of experience. This portfolio showcases projects built for international clients across California (USA), South Africa, and the UK — including e-commerce platforms, SaaS tools, and payment integrations.

## Tech Stack

- **Framework:** React 19 + Vite 8
- **Animations:** Framer Motion
- **Styling:** Vanilla CSS with custom design system
- **Deployment:** Vercel (auto-deploy on push to `main`)
- **Icons:** Lucide React

## Run Locally

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`
